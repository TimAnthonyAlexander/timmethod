# W10-01 · Onboarding

**Wave:** 10 — Ship Readiness
**Status:** open
**Depends on:** W6-07, W8-01
**Spec:** §14.3, §18

## Goal
First launch to first counted rep, without confusion.

## Why
Full-featured means full-featured, whether it lands on one phone or a million.

## Do
- [ ] What the app measures, in three screens, honest about the boundary
- [ ] Camera permission with the pre-prompt explainer (W6-03)
- [ ] Phone placement tutorial: distance, height, angle, what full-body framing looks like
- [ ] Plate configuration — the one setup step that materially affects accuracy
- [ ] Pick starting exercises from the catalog
- [ ] A first guided set with live coaching on framing
- [ ] Skippable, resumable, and never shown again once completed

## Done when
- [ ] A cold install reaches a correctly counted set without external explanation
- [ ] Skipping leaves the app fully usable
- [ ] Plate configuration cannot be accidentally bypassed for loaded exercises

## Notes
The placement tutorial is the highest-leverage screen in the app. Camera angle is the top documented failure mode, and this is the only place it gets addressed before it causes a bad first impression.
