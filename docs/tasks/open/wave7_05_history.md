# W7-05 · History and trends

**Wave:** 7 — Sessions & Persistence
**Status:** open
**Depends on:** W7-01
**Spec:** §12, §14

## Goal
Look back at sessions, exercises and progression over time.

## Why
Progression is the whole point, and it is invisible without history.

## Do
- [ ] Session list, then session detail, then set detail
- [ ] Per-exercise: load over time, first-rep velocity at a given load over time, ROM baseline over time
- [ ] Swift Charts, honouring the three-token palette
- [ ] Velocity-at-load is the most informative chart in the app — give it room
- [ ] Export to JSON, since this is personal data on a personal device

## Done when
- [ ] Trends render on a 200-session synthetic database without lag
- [ ] Charts use no colour outside the token set
- [ ] Export round-trips

## Notes
First-rep velocity at a fixed load, tracked over weeks, is the closest thing to an objective strength readout this app can produce without 1RM testing. Treat that chart as a headline, not a detail view.
