# W7-04 · Set summary

**Wave:** 7 — Sessions & Persistence
**Status:** open
**Depends on:** W7-03, W6-04
**Spec:** §14.1, §7.3

## Goal
What the screen shows between sets.

## Why
This is where ROM, partials and velocity loss belong. During the set there is one number worth seeing; after it there are several.

## Do
- [ ] Reps, partials shown separately and honestly
- [ ] Velocity loss reached, and whether the cutoff was hit
- [ ] Mean concentric velocity, first rep and last rep
- [ ] ROM as percentage of your own baseline, with the trend across the set
- [ ] Bar path for the set, if Track A was active
- [ ] Rest timer running, with the §11.4 guidance visible but not enforced as a countdown
- [ ] A one-tap correction if the count was wrong, and that correction feeds back into the fixture backlog

## Done when
- [ ] Every number on this screen traces to a stored field
- [ ] Correcting a count writes a flagged record for later review
- [ ] Partials are never silently folded into the rep count

## Notes
The correction affordance is also a data collection mechanism. A wrong count you can tap is a labelled failure case, which is worth more than a wrong count you shrug at.
